# AGENTS — x2ai-voice-avatar

Плагин-компаньон для OpenCode Desktop: пиксельный персонаж в левом нижнем углу,
озвучка ответов и рассуждений локальным TeraTTSv2, артикуляция по длительности
звука, своя панель настроек. Всё офлайн. Общие правила процесса — в
`~/Documents/AGENTS.md`, здесь только проектное.

## Три части

| Что | Исходник | Живая копия |
| --- | --- | --- |
| GUI | `plugins/x2ai-avatar/gui.template.cjs` → сборка `gui-experimental.cjs` | `~/.config/opencode/plugins/x2ai-avatar/` |
| Серверный плагин | `plugins/x2ai-tts-done.js` | `~/.config/opencode/plugins/` |
| TTS-сервер | `x2ai-teratts/server.py` | `~/.config/opencode/x2ai-teratts/` |

Паки спрайтов: `packs/pixel/` (наш, в git), `packs/anime/` (чужой, в `.gitignore`).
Черновые кадры и прочий локальный мусор — `custom/` (в `.gitignore`).

## Цикл разработки

```sh
python3 tools/pack_sprites.py && python3 tools/build.py
cp plugins/x2ai-avatar/gui-experimental.cjs ~/.config/opencode/plugins/x2ai-avatar/
cp -R plugins/x2ai-avatar/packs ~/.config/opencode/plugins/x2ai-avatar/  # кадры паков
cp plugins/x2ai-tts-done.js ~/.config/opencode/plugins/
cp x2ai-teratts/server.py ~/.config/opencode/x2ai-teratts/   # если менялся сервер
pkill -x x2ai-voice                                          # перезапуск TTS
python3 tools/smoke.py                                       # ждём «Всё в порядке»
```

`smoke.py` ничего не копирует — он сверяет байты репо с `~/.config` (включая
`packs/`) и пишет «устарело: … — скопируй …». GUI подхватывается только после
**Cmd+R** в окне; серверный плагин перезагружается на каждом шаге сам.

## Ловушки

1. Бандл исполняется через `new Function` — в нём нет `require`, только
   аргументы, переданные сборкой.
2. Серверный плагин перезагружается на каждом шаге: любое состояние (правила,
   лимиты, mute, имена, счётчики имён) обязано жить в файле.
3. `pkill -f x2ai-teratts` сервер не находит (argv переписан `setproctitle`).
   Только `pkill -x x2ai-voice`, проверка — `ps -p PID -o comm`.
4. Английский тег обязан доехать до движка: в `speakTera` в stdin пишется
   `<en>…</en>`, иначе фраза звучит с русской фонетикой.
5. `/state` отдаёт **остаток** `ms` и `at`; окно считает `elapsed = now − at`
   и пропускает прошедшие кадры партитуры.
6. `apply()` меняет голос после анимации 175 мс — перерисовку панели после
   выбора персонажа делать с задержкой 430 мс.
7. Голоса хранятся по языкам (`voiceByLang`); русский выбор не подставлять в
   английский.
8. `mute` — отдельный флаг, не подмена `mode`/`reason`.
9. `/test` идёт через `speak()`, а не `speakTera`: иначе в state нет текста и
   губы не двигаются.
10. Стоп глушит только свой чат: STATE гасится, только если останавливаемый
    sid совпадает с текущим.
11. Губами двигает только чат, чей sid в state; при переходе в другой чат
    артикуляцию надо гасить (`pollBridge`).
12. `<dcp-…>` в выводе shell съедается как HTML-тег — regex в `stripCode`
    проверять через `read`/`grep`, а не через `sed`.
13. Кадров спрайтов в бандле нет: окно берёт пак с моста (`GET /pack?name=`),
    манифест — `GET /packs`. Пустой пак рисует прозрачный кадр, поэтому пак
    обязательно копировать в `~/.config/opencode/plugins/x2ai-avatar/packs/`.
14. Настройки движка (mode, speed, lang, muted, quiet) — в
    `x2ai-speech.json`; настройки окна (пузырь, хоткеи, реакция на ошибки) — в
    localStorage `x2ai-avatar:ui`; манера речи персонажа — в
    `x2ai-char-style.json` по sid.
15. В серверном плагине POST-маршруты обязаны жить в обработчике `req.on("end")`:
    выше тела запроса `payload` не существует, и `POST /settings/export`
    отвечал пустотой. GET-маршруты — до чтения тела.
16. Закрытые вкладки не озвучиваются: окно шлёт список открытых чатов
    (`POST /open` → `x2ai-open-sessions.json`, изменение + heartbeat раз в 5 с),
    сервер сверяет sid в `tabOpen()`. Файл устарел (>30 с) или пуст — озвучка
    не блокируется, иначе окно без отчёта немое. Пропавшие sid сразу глушатся.
17. `mute` теперь на чат: `x2ai-muted.json` = `{last, bySid}`; при mute сервер
    пишет фразу в `x2ai-avatar-note.json` (`noteSilent`), `/state?sid=` отдаёт
    её в `note`, окно показывает пузырь без звука и артикуляции.
18. Режим пузыря — `uiPrefs.bubble`: `off` / `mute` (только при выключенном
    звуке, по умолчанию) / `always`; главнее всегда режимы озвучки: если ответ
    или рассуждения «отключено», пузырь не появляется (`bubbleChannelOn`).
19. Эмоции: сон (`IDLE_MS` 3 мин, наклон через кейфрейм `x2ai-sleep`) и злость
    на ошибки (`rageQueue` + `x2ai-rage`, красная подсветка, кадр `wide`).
    Речь эмоцию не сбрасывает; гасит только галочка «Живой персонаж».
20. Клик по персонажу — только по самому спрайту (`box.onclick` проверяет
    `event.target === img`); панель и пузырь кликом по персонажу не считаются.
21. Реплики ошибок и компактизации — по 5 вариантов на язык: свои у персонажа
    только при включённом «Характере» (`RAGE_BANK.chars` / `COMPACT_BANK.chars`),
    иначе нейтральные по полу (`neutral.m` / `neutral.f`, выбор — `pickByTemper`).
    Правя банк, сохраняй по 5 строк: иначе выбор снова станет предсказуемым.
22. Гнусавость Гопника — `NASAL` в `x2ai-teratts/server.py`, ключ — базовый
    голос `ru_m5`; `_eq` (FFT) применяется в `apply_fx` до `FX`. Поэтому у
    `fx_demon` (его база тоже `ru_m5`) голос не гнусавит: ключ там `fx_demon`.
23. Смешанные голоса — `tools/make_voice.py` (`--mix "ru_m5:0.45,ru_m1:0.35"`,
    `--label "Гопник"`): веса нормализуются, стиль кладётся в
    `teratts-model/styles/<id>`, метка — в `x2ai-voice-labels.json`. Панель
    берёт такие стили сама (`extraVoices()` в `x2ai-tts-done.js`), перезапуск
    сервера не нужен; гнусавость для нового id прописывается в `NASAL` руками.
24. Хриплость — `RASP` в `x2ai-teratts/server.py` (`_saturate` + `_rasp`:
    понижение, необязательное `vibrato` («пьяное качание» у `x2ai_alkash`),
    сатурация, эквалайзер), применяется в `apply_fx`, только когда у голоса нет
    `FX`. Новый персонаж добавляется в семи местах: папка кадров
    `packs/pixel/<id>` (+ собрать `sprites.json`), `VOICE_ALIAS`,
    `CHAR_NAMES`/`CHAR_NAMES_EN`, `TERA_ORDER` (и `TERA_VOICES` в серверном
    плагине), `RAGE_BANK.chars`, `COMPACT_BANK.chars`, `clicks.json`; пол
    смешанного голоса задаётся руками (`MALE_VOICES`, `lineGender`,
    `MIXED_GENDER`).
25. Перевод рассуждений делает только вспомогательная модель. Аварийного
    Google-перевода больше нет: его подстрочник звучал как бред, поэтому при
    ошибке модели `translateText()` возвращает пусто и `speakReason()` пишет
    `SKIP: reason not translated` — персонаж молчит. Исходник читается вслух
    только если он уже на языке озвучки (`REASON: translate failed, original`).
    Логи: `TR:` / `TR_ERR` / `TR: still not <lang>` / `TR: no model, silence`.
26. Сторона окна — `uiPrefs.side` (`left`/`right`) в «Дополнительно» плюс своя
    у персонажа (`charSettingsFor(key).side`, пусто — общая). Всё висит на
    `box`, поэтому `applySide()` двигает спрайт, три кнопки, панель и пузырь
    вместе; хвост пузыря и «z» переставляются на другой край. Кадры
    персонажей из `MIRROR_CHARS` (сейчас `x2ai_novyi_russkiy` и
    `x2ai_bratok`) обрезаны
    с краю и отражаются через `img.style.scale = "-1 1"` только на правом
    краю: слева кадр стоит как нарисован, справа зеркалится, чтобы обрез ушёл
    за край окна. Персонажи из `MIRROR_LEFT_CHARS` (сейчас `fx_ghost`)
    нарисованы смотрящими вправо и зеркалятся наоборот — только слева.
    Именно `scale`, а не `transform`: иначе зеркало терялось на
    анимации смены персонажа.
27. «Все доступные» — виртуальный пак `ALL_PACK = "@all"`: `packVoices("")`
    объединяет всех без повторов, `ensurePack("@all")` грузит все паки,
    `frameSetFor()` ищет кадры по всем пакам. Включения — отдельный список
    `enabledMap["@all"]`, настройки — ключи `@all::<id>` через `settingsKey()`
    (в `charSettingsFor`/`saveCharSetting`). Поэтому один персонаж в паке и в
    «все доступные» настраивается независимо; `nameFor()` в этом режиме
    ищет пак по id, иначе пиксельные имена терялись бы. Дефолты у паков и у
    «все доступные» одинаковые: `seedPackSettings()` работает по общему
    правилу, без особых значений для виртуального пака.
28. Сокет TTS может исчезнуть при живом сервере. Тогда
    `x2ai-teratts-speak` получает rc=3 и **не** удаляет сокет: иначе сервер
    остаётся жив, держит flock, новый пишет «already running», а все фразы
    теряются. `send.py` различает 3 (файла нет) и 4 (файл-мусор,
    `ECONNREFUSED`) — во втором сокет снимается. Если после старта сокет так
    и не появился за 10 с, обёртка снимает `x2ai-voice` и поднимает сервер
    ещё раз. В `server.py` watchdog: пропал файл сокета → `socket vanished,
    exit`, чтобы следующий запрос поднял сервер заново.
29. Ударения в словаре RUAccent местами неверные («горе» → «гор+е»,
    «милок» → «м+илок», «чепуш» в словаре нет). Поправка живёт в
    `x2ai-teratts/server.py` сразу после `load_model`: `tts.accentizer.accents`
    дополняется словарём `STRESS_FIX` (формат движка — «+» перед ударной
    гласной). Текст реплик и пузыря при этом не меняется.
30. Кнопка питания (`powerBtn`) — общий выключатель: `uiPrefs.enabled` в
    localStorage, сервер получает `POST /power {on}`. Кнопка живёт в `root`,
    а не в `box`: при выключении `box` прячется целиком, а она остаётся на
    нижнем краю всегда видимой (без hover). Выключение пишет
    `x2ai-tts-done.disabled`, глушит `x2ai-voice` и режет события и `/say`
    (`reason:"off"`); включение удаляет файл и поднимает сервер через
    `startEngine()`. Панель при выключении закрывается, `paintBubble`,
    `resetIdle` и `pollBridge` при off не работают.
31. Окно шлёт id пака (`px_fx_ghost`), а движок знает только базовый голос.
    `speakTera()` и `POST /voice` снимают префикс `px_` — без этого
    `TERA_EXIT 1` и тишина. Новый пиксельный персонаж должен быть в
    `VOICE_ALIAS` (иначе `charVoice` отдаёт неизвестный id), а его ключ
    `px_<id>` — в `clicks.json`; `clicks.json` — только `{text}`,
    предгенерированного аудио в плагине больше нет.
